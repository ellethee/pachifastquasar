# @ilpachi/pachifq

Scaffolding CLI for apps and features built on `@ilpachi/pachifastquasar`.
An app generated by `pachifq create` has only a few lines of configuration and depends on the
shell package; new vertical features live in `src/features/**` of the app.

> **Status: beta.** Scaffold CLI for frontends of pachifast (Python backend by the same author). API and generated layout may change between releases (0.x).

```bash
pnpm dlx @ilpachi/pachifq create my-app     # one-off
pnpm add -D @ilpachi/pachifq                # or as a dev dependency
pachifq create my-app
cd my-app && pnpm install && pnpm dev
pachifq new feature invoices --title "Invoices" --yes
pachifq new locale fr
```

| Command | Alias | Page |
| --- | --- | --- |
| `pachifq create` | `c` | [create](commands/create.md) |

Global flags: `-h`/`--help`, `-v`/`--version`, `--no-color`. The CLI output is in Italian.
