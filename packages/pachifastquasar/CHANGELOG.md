# Changelog

All notable changes to `@ilpachi/pachifastquasar` are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html)
(the package is in the `0.x` series: minor releases may contain breaking changes).

## [Unreleased]

### Fixed

- Dev proxy: the `/api` proxy now rewrites `Origin` to the target (not only `Host`), so the cookie refresh (`auth.csrf_rejected` otherwise) works under `pnpm dev` without `refresh_allowed_origins`.

## [0.1.5] - 2026-10-20

### Added

- `http.errorDisplay` (`'dialog'` default | `'toast'`) and `http.toast` (`position`, `timeout`; env `QCLI_HTTP_ERROR_DISPLAY`, `QCLI_HTTP_TOAST_POSITION`, `QCLI_HTTP_TOAST_TIMEOUT`): HTTP errors can be shown as configurable toasts.

### Fixed

- Dashboard: the card grid now has 3 / 2 / 1 columns by width (`minmax(0, 1fr)`); on a phone the cards were squeezed into a third of the width and cut.

## [0.1.4] - 2026-10-20

### Added

- `auth.refreshMode` (`QCLI_AUTH_REFRESH_MODE`): opt-in `'cookie'` mode where the refresh token is an HttpOnly cookie managed by the pachifast backend (`auth.refresh_mode` `cookie`/`both`). Login and MFA verify use `credentials: 'include'`, `/refresh-token` and `/logout` send the body `{}` and the `X-Pachi-Auth: refresh` header (`PACHI_AUTH_REFRESH_HEADER`), nothing is persisted (access token and user in memory), the guard always tries a silent refresh on load, tabs coordinate with the Web Lock `pachi-auth-refresh` and the BroadcastChannel `pachi-auth` (no tokens on it). The default `'body'` mode is unchanged.

## [0.1.3] - 2026-10-14

### Changed

- Fix: a route with children and no component (the shape generated by pachifq new feature --children) returned the 404 page instead of the children dashboard; the shell now makes such parents navigable.

## [0.1.2] - 2026-10-14

### Changed

- Accessibility: the dashboard card parent-level button now has an accessible name (aria-label).

## [0.1.1] - 2026-10-14

### Changed

- First release published from GitHub Actions with trusted publishing (npm provenance). Docs: security page and README note about the build-time `braces` audit notice.

## [0.1.0] - 2026-10-14

Initial public release. Vue 3 / Quasar application shell for pachifast backends.

### Added

- Layout with app bar, breadcrumbs, light/dark theme and account menu.
- Optional authentication: login, silent session restore, token refresh and per-route authorization.
- Automatic card dashboard built from the route tree, with optional route widgets.
- Router and menu assembled from the routes and menus of the app features and of the installed packages.
- Internationalization on `@ilpachi/pachi-i18n` (Italian and English out of the box).
- HTTP client on `@ilpachi/use-alova`, wired to authentication, spinner and error messages.
- Runtime configuration through `QCLI_*` environment variables or code, and the Quasar preset `definePachiQuasarConfig`.
